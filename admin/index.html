Content management
for the Library

This is the Decap CMS entry point. It edits news and events, pages, services, the subscribed database list and the opening hours settings.

To activate it, deploy this folder to a Git connected host, then set the backend in admin/config.yml. On Netlify enable Identity and Git Gateway. On GitHub use backend: github with the repository named. Without that connection the editor loads but cannot sign anyone in.
